# Suara perayaan

Taruh file audio di folder ini. Setiap file otomatis muncul sebagai pilihan di
**Pengaturan → Suara perayaan**, tanpa perlu mengubah kode.

- Format: `.mp3`, `.ogg`, `.wav`, `.m4a`, `.aac`, atau `.webm`. Paling aman `.mp3`.
- Nama di menu diambil dari nama file: `tada-meriah.mp3` → **Tada meriah**.
- Urutan: awali nama file dengan angka, misalnya `01-tada.mp3`, `02-confetti-pop.mp3`.
  Angkanya tidak ikut ditampilkan.
- Durasi ideal 0,5–2 detik dan ukuran di bawah 100 KB, karena suara ini diputar setiap kali
  todo selesai.
- Gunakan hanya suara yang boleh kamu pakai (buatan sendiri atau berlisensi bebas).

Setelah menambah atau menghapus file, jalankan ulang `npm run dev`, atau push ke GitHub
supaya Vercel mem-build ulang.
